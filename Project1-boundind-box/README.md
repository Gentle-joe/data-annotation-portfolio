Project 1: Object Detection with bounding boxes 

OVERVIEW
This project demostrates object dection annotation using bounding boxes on a dataset of 19 images containing cars, bikes, people.

tools Used 
- **ANNOTATION TOOL:**label studio
-** Export Formats: COCO, YOLO

## Labels 
|Label  | Color |Description |
|-------|-------|------------|
|car    |Red    |All types of cars|
|bike   | Green | bicycles |
|person | Blue  | Human figures | 

## Dataset
 -Bounding boxes drawn tightly around each object
 -All visible objects labeled including partially visible ones
 -Separate boxes drawn for overlapping objects
 
## Export Formats 
- `coco-export/` — COCO JSON format (used by Meta, Microsoft, research labs)
- `yolo-export/` — YOLO format (used for real-time object detection)

## Skills Demonstrated
- Object detection annotation
- Multi-class labeling
- COCO and YOLO format familiarity
- Label Studio proficiency
